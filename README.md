# 🎉 Event Management System

A simple and beginner-friendly **Event Management System** built using **Spring Boot** and **Thymeleaf**.

---

## 🚀 Features

✅ Create New Events
✅ View All Events
✅ Simple and Clean UI
✅ Spring Boot MVC Architecture
✅ Thymeleaf Integration

---

## 🛠️ Technologies Used

* Java
* Spring Boot
* Spring MVC
* Thymeleaf
* Maven
* HTML/CSS
* Git & GitHub

---

## ▶️ Run the Project

### Clone Repository

```bash
git clone https://github.com/AashishKumarOfficial/Event-Management-System.git
```

### Open Project

Open in IntelliJ IDEA or any Java IDE.

### Run Application

Run:

```text
EventManagementSystemApplication.java
```

### Open Browser

```text
http://localhost:8080/create
```
